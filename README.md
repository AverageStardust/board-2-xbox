# Board-2-Xbox
Board-2-Xbox maps input from a Wii balance board from xwiimote to a virtual xbox controller. Leaning moves the left joystick. Jumping presses the A button, or south button. Testing has only been done on Debian Trixie.

## Running
There is a linux release, it must be run from the command line.

## Building
Installing golang is a prerequisite. Download the source code, change directory to the source directory and run `go build`
